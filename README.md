# あさごはんタイマー

子どもが時間どおりに朝ごはんを食べきれるように作った、見てわかるカウントダウンタイマーです。

https://muonsay.github.io/asagohan-timer/

## できること

- 色の円が少しずつ減っていくので、時間の感覚がまだない子にもわかる（最大60分）
- 「7:00 まで」のように終わる時刻で決めるか、「20分」のように長さで決めるかを選べる
- 残り5分と終わったときに音でお知らせ
- 7種類のきせかえ（いつもの・ゆめかわ・うさぎ・スイーツ・おはな・うみ・よぞら）
- ホーム画面に追加するとアプリのように使え、オフラインでも動く

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | アプリ本体 |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・色 |
| `sw.js` | オフラインで動かすための Service Worker |
| `icons/` | アイコン画像 |

## 公開のしかた（GitHub Pages）

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、**Branch** を `main` / `/ (root)` にして保存
3. 数分後に上の URL で開けるようになる

## アプリを更新したとき

`sw.js` の `VERSION` を `v2`, `v3` … と上げてください。ホーム画面のアプリにも新しい版が届きます。
